Schritt 2

So spielt es sich

Grundprinzip

Elli tapst automatisch nach rechts. Ihr Körper verhält sich wie ein umgedrehtes Pendel: Je schiefer sie steht, desto schneller kippt sie weiter. Ein Tipp gibt einen kleinen Schubs zurück zur Mitte. Über 45° heißt es Plumps!

Punkte

  • 1 Punkt pro Schritt
  • Luftballon einsammeln: +5
  • Keks: Elli wackelt 3 Sekunden ruhiger

Es wird schwerer

  • Elli wird mit der Zeit schneller und wackliger
  • Bauklötze und Teppichkanten geben einen Stolper-Stoß
  • Die Katze huscht vorbei und lenkt ab

Für Party-Gäste gedacht

  • Eine Runde dauert 30–90 Sekunden
  • Nur zwei Tippflächen, keine Anleitung nötig
  • Optional: Handy neigen statt tippen
Schritt 3

Recherche: Varianten für das Balance-Spiel

Bekannte Wackel-Lauf-Spiele wie QWOP oder Daddy Long Legs zeigen: Eine einzige, einfache Eingabe reicht, und das Hinfallen mit sofortigem Neustart macht den Reiz aus. Daraus ergeben sich drei Varianten.

Empfehlung

A · Hand reichen

Elli läuft allein, du tippst links oder rechts, um sie aufzufangen. Sofort verständlich, funktioniert auf jedem Handy.

Alternative

B · Schritt für Schritt

Abwechselnd links und rechts tippen setzt jeweils einen Fuß. Wer aus dem Takt kommt, gerät ins Wanken. Lustiger, aber schwerer für Ältere.

Zusatzmodus

C · Handy neigen

Balance über den Lagesensor. Auf dem iPhone muss man dafür erst eine Erlaubnis antippen, und das klappt nicht immer zuverlässig. Daher nur als Extra.

Schritt 4

Technik: kostenlos und ohne Login

QR-CodeAuf einem Aufsteller am Tisch. Führt zur Spiel-Adresse.
→
GitHub PagesDas Spiel als eine HTML-Datei aus diesem Repo. Adresse: syuux77.github.io/Elli1
→
Apps ScriptKleines Google-Skript als Web-App. Liest die Top 10 und nimmt neue Punkte an.
→
Google TabelleSpalten: Zeit, Name, Schritte. Du siehst jeden Eintrag live.
  • Das Spiel wird mit purem HTML, Canvas und JavaScript gebaut. Keine App, kein Build-Schritt, lädt auch im schwachen WLAN schnell.
  • Die Punkte werden als einfacher Text gesendet. So umgeht man die bekannten CORS-Probleme mit Apps Script.
  • Das Skript prüft Name (max. 16 Zeichen) und Punktzahl auf Plausibilität. Für eine Familienfeier reicht das als Schummelschutz.
  • Fällt das Internet aus, läuft das Spiel trotzdem. Die Punkte werden später nachgesendet.
